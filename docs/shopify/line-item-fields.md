旧ストア（sugarnote.store、テーマ Rise 15.4.1）の3商品の商品ページに、宛名・メッセージの入力欄を付ける。
入力値は「宛名」「メッセージ」として、カートと Shopify の注文詳細に表示される。

|---|---|---|
| デコチェキ / レトロワンピース衣装(コメント付き) | 15461215928556 | 宛名 |

仕様は南さんの回答（2026-10-23）。3商品は 10/21 から販売中。

## 入力のルール（南さん回答 2026-10-23）

- 宛名・メッセージとも**必須**（デコチェキは宛名だけ、必須）
- メッセージは **100 文字まで**。宛名は上限の指定が無いので 20 文字
- 「即日販売開始」との回答（3商品は 10/21 から購入できる状態）。変えるときは `sn-line-item-fields.liquid` 冒頭の4行

## 作り

- `docs/shopify/sn-line-item-fields.liquid` を snippet として置き、商品ページの「カスタム Liquid」ブロックから呼ぶ。対象外の商品では何も出力しない
- テーマの購入フォームは `novalidate` なので、必須チェックは snippet の script で行う（submit を capture で受け、テーマの処理より先に止める）
- 欄がある商品では「今すぐ購入」ボタンを隠す（入力チェックを通らずに決済へ進めてしまうため）
- 同じ商品を複数枚買った場合、宛名・メッセージは1つの入力で共通（Shopify の標準の動き）
- ストアに入っている Infinite Options（入力欄のアプリ）は使わない。コラボレーター権限ではアプリの画面が開けないため（2026-10-23 確認）

### 注意

- トップのクイック追加（「おすすめ商品」の欄の追加ボタン）は商品ページを通らないので、この欄が出ない。**3商品をクイック追加のある欄に入れないこと**（2026-10-23 時点では入っていない）
- 対象の商品を増やすときは、`case product.id` に id を足す（商品の id は `https://www.sugarnote.store/products/<handle>.js` の `id`）

## 手元での確認（2026-10-23）

本番の商品ページの HTML に描画結果を差し込み、カートへの送信を横取りして Playwright で確認（390px / 1280px、全項目 OK）:
宛名が空欄だとカートに入らずエラー表示と宛名欄へのフォーカス／入力するとエラーが消える／カートに `properties[宛名]`・`properties[メッセージ]` が送られる（前後の空白は除く）／デコチェキは宛名だけ／「今すぐ購入」ボタンは非表示／対象外の商品では何も出ない。

## 反映手順（本番に出る。ユーザーの OK をもらってから）

**本番のテーマには直接書かない。** 複製したテーマで作って確かめ、その複製を公開する。元のテーマは下書きに残るので、戻すときはそれを公開し直す。

1. オンラインストア → テーマ → 公開中の「Rise」の「…」→「複製」。名前を「Rise 宛名欄 2026-10」にする
2. 複製の「…」→「コードを編集」→ `snippets` で「新しい snippet を追加」→ 名前 `sn-line-item-fields` → `docs/shopify/sn-line-item-fields.liquid` の中身を貼って保存
3. 複製の「カスタマイズ」→ 上のページ選択で「商品」→「デフォルト商品」→ 商品情報の中で Infinite Options のブロックの下に「ブロックを追加」→「カスタム Liquid」→ 中身に次の1行を貼って保存
   ```
   {% render 'sn-line-item-fields', product: product, section_id: section.id %}
   ```
   ブロックが購入ボタンより下に入ったら、ドラッグで購入ボタンの上に動かす
4. 複製の「…」→「プレビュー」で3商品と、対象外の商品を1つ開いて確かめる
   - 3商品: 欄が出る／空欄で「カートに追加」するとエラー／入力するとカートに入り、カートに宛名・メッセージが出る／「今すぐ購入」が出ない
   - 対象外: 何も変わらない
   - 支払いはしない。カートは確認後に空にする
5. 問題なければ、複製を「公開」する
6. 公開後、本番の3商品ページをシークレットウィンドウで開き、4 と同じ確認をする

**戻すとき**: テーマ一覧の下書きにある元の「Rise」を「公開」する。
