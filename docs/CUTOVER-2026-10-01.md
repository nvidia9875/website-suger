**知っておくこと（2026-09-27 実測）**
- 旧サイトは HSTS（`max-age=63072000`）を返している。一度来たことのある人のブラウザは、sugarnote.jp を https でしか開かない。そのため、**DNS が GitHub に向いてから GitHub の証明書が出るまでの間は、新サイトに来た人は開けない**（証明書エラーを無視して進むこともできない）。証明書の発行は通常1時間以内だが保証はない → 開始は **10/1 22:00**（先方に連絡済み）。DNS が切り替わっていない人には旧サイトが出続ける
- ムームーDNS は TTL を変えられない（3600秒）。反映は**目安1時間、それ以上かかることもある**。切り戻しも同じ
- 切り戻しの保険: Vercel に旧サイトとドメインが残っている間は、DNS を戻せば旧サイトに戻る。旧証明書の期限は **apex 2026-12-04 / www 2026-10-28**。DNS を GitHub に向けると Vercel は証明書を更新できなくなる可能性が高いので、**www の保険は 10/28 まで**と考える
- CAA レコードは無い（証明書発行の妨げは無い）

**切り戻しの判断期限（開始前に決めておく）**
- 開始時刻: **10/1 22:00**（伊藤さんに連絡済み）
- 判断期限: 「DNS check successful」になってから **3時間**（＝＿＿:＿＿）。この時点で `tls` がまだ FAIL（新サイトが開けない状態が続いている）で、`old` が OK なら切り戻す（5-2）
- 判断するのは自分。切り戻したら伊藤さんに連絡し、原因を調べてから別の日にやり直す
